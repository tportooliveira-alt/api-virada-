# `artifacts/` — Artefatos gerados de lançamento

Saídas prontas (copy + plano) pra executar o lançamento. Diferente de `marketing/`
(estratégia geral): aqui é o pacote específico de um lançamento.

## `artifacts/hotmart-launch/`
| Arquivo | O que é |
|---|---|
| `01-produto-hotmart.md` | Ficha do produto pra cadastrar na Hotmart |
| `02-copy-checkout.md` | Copy da página de checkout |
| `03-reels-instagram.md` | Roteiros de Reels |
| `04-mensagens-whatsapp.md` | Mensagens de WhatsApp |
| `05-sequencia-email.md` | Sequência de e-mail do lançamento |
| `06-plano-trafego-r300.md` | Plano de tráfego pago com orçamento de R$300 |
| `07-checklist-deploy.md` | Checklist de deploy pré-lançamento |
| `RELATORIO-NOTURNO.md` | Relatório de uma sessão de automação noturna |

> Muitos desses artefatos foram produzidos/aplicados pelos scripts Python de
> automação em `scripts/` (`hotmart_*.py`, `cakto_*.py`, `canva_*.py`).
